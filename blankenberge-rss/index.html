🌊 Evenementen in en rond Blankenberge

Gratis, dagelijks bijgewerkte RSS-feed voor uw toeristische website

📰 Abonneer op de RSS-feed

🔗 Feed-URL

Kopieer deze URL en voeg hem toe aan uw RSS-lezer of website:

https://kristofpoppe.github.io/aitests/blankenberge-rss/feed.xml

De feed wordt elke dag automatisch bijgewerkt om 08:00 (Belgische tijd).

📄 Wat bevat de feed?

Actuele evenementen in en rond Blankenberge, waaronder:

Strand & Kust Festivals Cultuur Kunst & Markten Vuurwerk Familie Rondleidingen Natuur

Elke <item> bevat: titel, datum, locatie, beschrijving en directe link naar meer info.

💻 Integratie op uw website

Voeg dit HTML-fragment toe om de feed te tonen via JavaScript:

<!-- Blankenberge Events RSS Widget -->
<div id="blankenberge-events">Evenementen worden geladen…</div>
<script>
fetch('https://api.rss2json.com/v1/api.json?rss_url='
  + encodeURIComponent('https://kristofpoppe.github.io/aitests/blankenberge-rss/feed.xml'))
  .then(r => r.json())
  .then(data => {
    const el = document.getElementById('blankenberge-events');
    el.innerHTML = data.items.slice(0, 5).map(item => `
      <article style="margin-bottom:1.2rem">
        <h3><a href="${item.link}">${item.title}</a></h3>
        <p>${item.description}</p>
      </article>`).join('');
  });
</script>

🔑 Automatische updates inschakelen (optioneel)

Voor de beste datakwaliteit via de officiële Publiq / UiT Databank:

  • Vraag een gratis API-sleutel aan via platform.uitdatabank.be
  • Ga naar uw GitHub-repository → Settings → Secrets and variables → Actions
  • Maak een nieuw secret aan met de naam PUBLIQ_API_KEY en plak uw sleutel
  • De feed wordt voortaan dagelijks automatisch gevuld met live evenementen

📌 Bron & technische details

  • Datakwaliteit: Publiq UiT Databank (officiële Vlaamse eventendatabank)
  • Fallback: scraping van uitinvlaanderen.be
  • Hosting: GitHub Pages – 100% gratis
  • Update-frequentie: dagelijks via GitHub Actions
  • Formaat: RSS 2.0 met Atom self-link
  • Broncode: scrape_events.py op GitHub
